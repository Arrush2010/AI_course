# Course Map

## Outcomes
Students will learn to use VS Code, Python, AI prompting, web interfaces, databases, APIs, data dashboards, report generation, automated tests, Git, and project documentation. They will build several small applications and one capstone.

## 12-week plan
1. Python calculator — variables, input, conditions, functions
2. Student marks manager — lists, dictionaries, validation, calculations
3. Expense tracker — CSV, dates, Decimal money calculations
4. To-do web app — HTML, CSS, JavaScript, browser storage
5. Student registration — Flask, SQLite, CRUD, server validation
6. Sales dashboard — Pandas, Streamlit, charts and filters
7. API lookup — HTTP, JSON, timeouts, errors and mock data
8. AI study assistant — model integration concepts, mock mode and secrets
9. Report generator — CSV validation and HTML report generation
10. Inventory and orders — relational data, transactions, business rules
11. Testing and release — automated tests, Git, configuration and rollback
12. Capstone — requirements, architecture, implementation, testing and demo

Suggested workload: 5–7 hours per week. Learners can take longer.

## Standard workflow
Understand the use case → define acceptance criteria → ask AI to plan → generate small increments → run in VS Code → test normal and failure cases → debug → improve → document.

## Required tools
VS Code, Python, browser, AI assistant. Git is recommended. Some labs use Flask, Streamlit, Pandas, Plotly or Requests. Lab 8 works in mock mode without an API key.

## Definition of done
A student can explain key functions, reproduce the setup, demonstrate required features, show test evidence, handle invalid inputs, document limitations, and explain how AI was used.
