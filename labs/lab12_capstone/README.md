# Lab 12 — Capstone
Choose a library tracker, booking prototype, budget dashboard, student portal, inventory tool, document summarizer, feedback dashboard or task manager.

Milestones: (1) requirements and acceptance criteria, (2) MVP scope, (3) architecture/data model, (4) implement one feature at a time, (5) tests and fixes, (6) security/privacy review, (7) README and demo, (8) reflection.

Use the capstone prompt in `../../course/AI_PROMPT_LIBRARY.md`. Do not ask AI to generate the entire project in one response.
